## Actual parser / shell

`parser_runner.py COMMAND...` sends one JSON object per line to a test adapter.
For each input call the **actual app parser/mapper** with raw bytes from raw_hex,
launched tool/version/nonce, actual exit, ordered folders and pair-present fact.
Return `{valid:BOOL,message:[CATEGORY,FACT]}`. These are test transport categories
defined by oracle.py, not a new shipping interface. Do not import oracle.py into
the app/adapter or decide results from fixture name/expected fields. Preserve raw
stdin/stdout/adapter source/build command and source hash. No shipping fake-outcome
switch. Test-only parser entry points do not establish G3 real-child execution.

The runner checks message selection for **invalid reports too**: a nonzero child
with malformed/stale/unknown report must use the generic fallback and cannot use
an ID-specific selector. Actual exit0 still needs its ordinary success facts
(including ingest's pair); malformed reporting alone cannot rewrite a child exit.
This tightens the initial198 adapter test, which asserted rejection without also
checking the invalid-report message. Use this corrected publication, not the old
runner, for candidate disposition. The original627 inputs/IDs/spec pins remain.

Drive every S4-CASES.json row in the actual shell through UI/OS events, with
timestamped process argv/hash/exit, state/widget snapshots and screenshots where
visual. Headless controller adaptation is Software's mechanics; the expected
outcomes are fixed. A skipped/unbuilt row remains HELD. Full native G1/G3/G4/G5,
elevation prompts/declines and physical G2 are not supplied by model fixtures.

Run static_controls.py against the actual CI check over app source. It copies
the source into disposable directories, appends nonexecuted Rust functions to an
existing app Rust file and invokes the supplied gate with APP_SOURCE_ROOT and cwd
pointing at the copy. A wrapper may adapt the existing gate invocation, not its
verdict. Source mutations never execute. Baseline and ordinary-file open must
pass; literal/aliased/data-flow device reads and partition write must fail. If
the implementation uses another source language, return equivalent compiling
source mutants for independent disposition before changing this package.
This checks detecting controls, not static-analysis completeness. Audit actual
app device targets/data flow and indirect helpers too; a blacklist of API names
alone is insufficient. The app can legitimately read reports and private files.
