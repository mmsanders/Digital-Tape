## Run

    make -C engine clean all
    make -C tests/wp10_backlog_adapter clean all
    python3 tests/wp10_backlog_adapter/run_product.py --evidence <fresh dir> \
        --retained tests/wp10_backlog_adapter/evidence/p1-r55-product
    python3 tests/wp10_backlog_adapter/run_product.py \
        --replay tests/wp10_backlog_adapter/evidence/p1-r55-product/observations.jsonl.gz \
        --retained tests/wp10_backlog_adapter/evidence/p1-r55-product --out <fresh dir>
    python3 -B tests/wp10_backlog_adapter/negative_controls.py <dir>/observations.jsonl.gz

With `--retained`, the fresh JSONL must equal the committed SHA-256 before replay. `--replay` works
offline.

`negative_controls.py` is non-canonical. It prints the per-row census of `oracle.check` outcomes:
79,820 pass and 0 fail. It then requires the oracle to reject 10 single-fact mutations of passing
Product observations; 10 were killed.

- **Row 1:** a chunk id ≥ `total_chunks`; a layout-preserving address; a changed source; a wrong
  `free_chunks`.
- **Row 2:** a frontier off by one; another post-crash metadata state; a changed chunk-store digest.
- **Row 3:** metadata changed before commit; a wrong remount; an extra service write.
