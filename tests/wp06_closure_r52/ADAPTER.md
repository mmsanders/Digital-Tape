# WP-06 R52 public-observation adapter contract

Build a separate adapter at the Product source identity supplied by PM. Do not import this oracle and do not inspect or expose Product-private state. Run the seven cases in `gap_plan.json` on a fresh file device per case. Emit one `wp06-r52-observation-v1` JSON object per line.

Each object contains `case`, `block_count`, public `calls`, callback `events`, and named raw `snapshots`. A call is `{step,fn,result,...}` and may add only public output fields such as `more_work` or `side_b_valid`. An event is `{step,op,ordinal,lba?,result?}` for every real `dev_read`, `dev_write`, or `dev_flush`; ordinals are contiguous and global within the case. Observation reads are not callbacks. A snapshot contains exactly `primary`, `mirror`, `A0`, `A1`, `B0`, and `B1` as lowercase hex: 512 bytes for each superblock and the entire 65,536 bytes for each index slot. Never emit adapter verdicts, selected-slot labels, derived `free_next`, internal phases, or parsed media fields.

Snapshot names are fixed by `oracle.check`: all cases use `before`; refusal cases add `after`; the record chain adds `after_arm` and `after_promote`; combined degraded cases add `after_reset` and `after_remount`. Mount calls report their public input as `side: "A"` or `"B"`. Capture refused-call snapshots byte-for-byte. Drive incremental promote/re-spool calls until `more_work == false`, retaining every call and callback under the same step. `E-RECORD-PROMOTE` uses steps `arm`, `record`, `commit`, and `promote`; it must feed/service real frames before commit, with `accepted` recorded from `tape_feed`. The two floor cases mount Side A while B has a live allocation strictly above `a_high_water`; the raw callback destinations, not an adapter claim, prove the allocation floor.

Retain the adapter source/build command and its SHA-256 next to the gzip JSONL. Replay with `python3 replay.py observations.jsonl.gz --manifest manifest.json --adapter-kind product --adapter-source-sha SHA --product-commit SHA --product-tree SHA`. Product observations require a later independent disposition; a passing replay is not self-acceptance.
