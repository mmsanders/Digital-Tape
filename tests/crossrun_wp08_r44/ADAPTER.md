# WP-08 R44 public adapter contract

At issued Product main `788cb765493096a076603e5ad4ac6e2dea47a7a9` / engine tree `054d27ab6e3e72f61118ff7d99e19e48741d05b2`, build a standalone adapter without importing this oracle. Construct one Side B raw index with **four distinct consecutive timeline runs** of lengths 5, 3, 7 and 2, mapped to distinct physical chunk IDs 1, 2, 3, 4 at `start_frame=0`. Write exact little-endian interleaved stereo PCM from the fixed seed `0xA51CE55D` into those chunks, including the short final run; use a valid DRAFT-9 superblock/index CRC. Preserve a byte-exact raw snapshot in **each** case: candidate superblock block, both B-slot header blocks and CRC-covered entry bytes, and the first 512-byte block at LBA `2048 + chunk_id × 1024` for each of the four chunks. The oracle parses the mapping, reads PCM through the raw entries and checks it against the independently generated seed. Adapter-provided `run_lengths` or `fixture_sha256` labels are ignored.

For every `oracle.cases()` entry, start from a fresh mount, `tape_seek(case.seek)`, `tape_set_rate(case.rate)`, service to completion, then render the same logical requested output with three subdivisions: `whole` (one render, service budget 256), `single` (one frame/render, budget 1), `uneven` (3/2 frame chunks, budget 7). For each variant, reset/mount before seeking so the ring and transport state are independent. Record each `tape_service` call's budget, `more_work`, result and **every raw callback event** (`op`, `lba`, `count` for reads/writes; flush event where applicable); keep calling until `more_work=false`. The oracle sums block counts from these events and rejects a budget excess; an adapter `blocks` scalar carries no authority. Record each `tape_render` call's requested/rendered frames, exact output PCM hex, result, `tape_tell` whole frame and `tape_status` endpoint flags immediately after it. `block_events` contains every callback event *during that render call* and must be empty. Instrument the same device callback wrapper for service and render. No hidden position or implementation interpolation labels are permitted. The oracle derives fractional Q32.32 position, floor interpolation and endpoint state independently.

Emit one JSONL object per case, `schema: "wp08-r44-v1"`, `case`, `raw_media: {superblock: hex512, B0: {header: hex512, entries: hex(12×count)}, B1: same, chunks: {LBA: hex512}}`, `seek`, `rate`, `variants` with `whole`, `single`, `uneven`; each variant has `render_sizes`, `service_budget`, `services: [{budget,result,more_work,events}]`, `renders: [{requested,result,rendered,pcm_hex,tell,at_start,at_end,block_events}]`. See `selftest.observation()` for an example schema, but do not use its synthetic outputs as Product evidence. `replay.py` demands all 33 IDs exactly once and binds the unabridged trace, oracle, plan, adapter source and Product SHA/tree in a non-overwriting manifest. Retain the adapter source/build command and raw fixture image separately; report any missing public `tell`/status/budget visibility as a concrete blocker rather than reading private engine fields.
