## Observation protocol

For editing, establish the listed full accepted value (or attempted rejected value)
through actual input/paste handlers, then the specified focus/UTF16 selection.
Capture `before` after that deliberate user action/selection and before the unrelated
snapshot(s); `after` follows the named deferred responses/events and settlement.
In two-edits/late-initial-snapshot cases, defer the older responses while setting
the latest value; baseline is the latest local edit before old responses resolve.
Capture the whole scenario's ordered action log including preparation. Do not
manufacture before values after the background event. No automatic wait can stand
in for receipt of the named completion. Invalid ASCII33bytes/multibyte34bytes/NUL
must not reach an accepted host label mutation or silently truncate.

For unchanged diagnostics, capture a genuinely open existing details control,
focus, actual DOM Selection anchor/focus (relative text-node path+offset), selected
plain text and scrollTop. Long typed stderr fixtures provide a real nonzero reading
position. Preserve those through unrelated snapshots. Test-document selection text
establishes copyable content; no actual OS clipboard/native-copy claim is made.
No added close/copy UI is required: deliberate Start over and diagnostic clear are
the existing closing actions in the cases. A changed diagnostic may hide/refresh
the panel; re-open if necessary to inspect current text. Unchanged diagnostics may
not collapse it. Late raw_details Promises cannot restore a superseded diagnostic.
Plain text/markup escaping/no lists and permanently disabled Make remain required.

The ordering cases add active label/details operations to the existing coordinator
boundaries. They are composed interaction deltas, not another parser/backend/
23-discovery corpus or actual child campaign. Reuse accepted gate/lifetime code
and accepted results by exact identity. Start over resets music/label and invalidates
old music results; independent current card polling/diagnostic remains its own
scope. Shutdown refuses due admissions and invalidates current outcomes. Old terminal/
owned cleanup must precede replacement. Destroyed binding receives no later DOM
mutation or remaining subscription. Pair raw backend operations with rendered
emissions; a handwritten expected trace or boolean alone is insufficient.
