# Mechanical Product adapter contract — read1 JSONL v1

Build a separate test executable around the public engine API and the imported
byte-identical `counting_device.[ch]`. This document contains no implementer design.
The package owns call schedules and expectations. The adapter supplies facts only:
no oracle imports, expected PCM, verdicts, filtering, port cache or rewritten tests.

## Transport and device

The executable reads one JSON object per stdin line and writes one response per stdout
line, flushing each response. Diagnostics go to stderr. Echo `ordinal` exactly.
Exit 0 on EOF. Every response includes integer `result`; public calls also include
`counters` with exactly the five per-call delta fields in OBSERVATION.md.

`init` supplies fixture metadata/semantic SHA, image_path, trace_path, writable,
play_ring_len=65536, rec_ring_len=65536, and optional control/shipping selectors.
Allocate caller-owned instance/rings, then tape_init. Open the independent device
with block_count/seed/writability from the fixture. Bind read1_read/read1_flush
directly, and bind **literal NULL** write if writable is false, otherwise read1_write.
Return `write_callback_null` from the actual binding. The init response needs no
counter object. The sparse image's payload holes are intentional: the independent
backend generates every untouched chunk block at each callback. Do not bypass it
with a normal file port. Real writes override generated bytes through its dirty map.

The backend emits each requested callback as a binary 20-byte LE record:
op/lba/count/rc/completed (all u32). 1=read,2=write,3=flush. Callback failure has
completed=0 even when it modified some destination bytes. The runner reads this
file independently after each command; the adapter never invents event records.
Retain callbacks.bin, exact adapter source/build/binary identities and logs.

On remount-change, `replace_unmounted_fixture` closes/reopens the fixture backend,
resetting its dirty map and seed using the supplied fixture. It performs no engine
operation. This tests a clean cold remount with changed content and the same UUID,
without an accepted warm descriptor. It does not claim concurrent external mutation.

## Public commands and additional factual outputs

All named public commands call their corresponding frozen `tape_*` function exactly
once, except the read-only render snapshots below. No adapter render/service batching.

| Command | Input | Additional factual outputs |
|---|---|---|
| tape_mount | side A/B, resume, warm descriptor or null | counter deltas only |
| tape_set_rate | signed int32 rate | counter deltas only |
| tape_seek | uint64 frame | counter deltas only |
| tape_set_side | A/B | counter deltas only |
| tape_service | uint32 budget | boolean more_work |
| tape_render | uint32 frames | rendered, pcm_hex of exactly rendered LE s16 stereo frames, position_frame, at_start, at_end |
| tape_get_info | none | warm_start_used (actual tape_info) |
| tape_tell | none | position_frame |
| tape_status | none | at_start, at_end |
| tape_arm | record mode 0/2 | counter deltas only |
| tape_feed | frames, pcm_hex | accepted |
| tape_commit / tape_abort | none | counter deltas only |
| tape_unmount | none | position_frame (unmount out-parameter) |

Render position/status are obtained from the public tape_tell/tape_status calls
immediately after render. Their actual entry/copy/loop work belongs in the command's
delta; all their device callbacks remain in the independent trace. They may not read
private Product state or reconstruct values from the requested schedule.

Warm data_hex is the exact caller buffer; null-data means a NULL data pointer.
data_bytes, valid_frames, start_frame, UUID and side are passed unchanged, including
deliberately inconsistent/overflowing values. Do not normalize them into valid input.

`inject` sets the independent backend's next read/write/flush failure fields, with
no engine call or counter object. fail_read_prefix copies that many blocks before
returning nonzero; the rest is poisoned. Engine success cannot be manufactured from
that incomplete callback. All failures are on test-owned media.

## Actual test-only seam controls

`seam_work` is a private test bridge command, not a new public engine callback/API.
It must execute the requested actual refill/adoption copies, retained-range movement,
entry inspections and helper loop bodies through the same observation primitives
used by Product sites, on isolated test-owned storage. Return the observed deltas.
Do not assign counters from the request, estimate byte/visit totals or return literals.
Volatile sinks may prevent the deliberate control work being optimized away. The
zero request must perform none of the counted work. Sites are independently audited
after the corresponding package is authored. Source/assembly confirms actual work.

The `control` init selector enables one **real executed** defect intervention:

| Control | Causal action (ordinary exact outputs preserved where unrelated) |
|---|---|
| whole-window-reread | force rereading a whole covered play window on ordinary advancement |
| tiny-transfer | split otherwise contiguous large-budget payload requests into count=1 callbacks |
| full-index-rescan | actually inspect every selected entry for each requested payload block on max-E long fixture |
| retained-movement | actually relocate retained PCM during ordinary advancement |
| stale-side | permit previously valid old-side samples after side invalidation |
| stale-content | serve old buffered samples after successful overwrite commit |
| stale-warm | adopt samples different from the supplied valid warm buffer |
| missing-lookahead | use a in place of required b at fractional interpolation |
| budget-overrun | issue a real count exceeding the remaining service budget |
| idle-nine-loops | execute nine counted playback-helper loop bodies on already-done idle service |
| idle-mapping | perform a real mapping-entry inspection on that idle path |
| invented-zero-seam | suppress real seam deltas while seam_work performs its requested work |

Do not satisfy these controls by fabricating observations/events. The precise
rejection reason is checked by controls.py so an unrelated crash cannot count.
Implementation-specific control-site plumbing is allowed only as test-only binding,
after this independent publication, and is absent from shipping builds.

Name every new observation/control definition/reference/storage with the reserved
`TAPE_READ1_` or `tape_read1_` namespace so ordinary preprocessing, objects and link
artifacts can authenticate its absence. Shipping preprocessing uses -E/-P (no
definition-dump mode), for the exact compiled shipping engine TUs. The observation
definitions/calls/storage themselves must be conditionally absent, not merely
unreferenced. Include actual nm/objdump/section and link-map records, TU/build census,
exact source/head/engine/binary/flags identities and a deliberately leaked marked
site/storage control built from the same held head. `absence.py` requires all three
layers and authenticates raw files by SHA256. Its marker check supplements the
independent covered-site/preprocess/body/storage audit; no name-only scan can prove
absence of anonymized or uncounted instrumentation.

## Provenance and shipping

Publish exact adapter sources/tree/binary SHA256, compiler flags, Product head and
engine tree, verifier import/publication identities, and raw trace/observation hashes.
Run the same complete canonical case list against an actual shipping-engine build.
It returns the same factual public outputs; counters are omitted (runner inserts
zeros for its side of the comparison). The normalized public observation/device
trace digests must be identical. Production absence requires preprocess/object/link
and actual-site/idle-path audits in READ2.md, beyond symbol-name absence.

The per-RPC 120 s harness ceiling and finite service orchestration loop are hang
detectors, not performance acceptance criteria or permission to waive a case. Host
time remains diagnostic. No Product acceptance follows from adapter compilation.

The issued zero-budget criterion is regression preservation. Supply the same public
call bridge linked to the pre-change accepted engine at pinned Product input
`9e902cf04b6d0c02363870fb9bc201e40239b509` as --baseline-adapter, compiled without
this new seam. Only the small canonical budget-zero case runs against it. The
runner compares the actual result with the candidate and independently checks zero
I/O/unchanged position/flags. No zero-budget result is invented from private source.
Record baseline source/engine/build/binary identities; this small differential does
not replace or repeat the Phase1 regression qualification.
