## Interface and acceptance authority

The normative engine behavior remains the authenticated DRAFT-8 bundle. This file
supplies the deterministic scrub table referenced, but not enumerated, by the
acceptance firmware criterion: “4.0× at t=0, linear to 12.0× at t=1.5 s, hold;

meaning. The 500 ms hold is the golden observation window; product firmware keeps

## Exact public-call schedule

Use one deterministic non-constant Side-A timeline of at least 1,000,000 stereo
frames. That length exceeds the table's 776,160-frame nominal forward advance and
keeps both cases away from the opposite endpoint. Verification owns the independent
fixture waveform and candidate PCM.

- Forward: mount Side A at frame 0 with `warm == NULL`; execute rows 0–15.
- Reverse: mount Side A at frame 0 with `warm == NULL`, seek to `total_frames`, then
  execute rows 0–15 using the reverse column. The DRAFT-8 reverse-from-end snap rule
  determines the first sample.
- Within every row, produce the stated total in render requests of 128 output frames,
  plus one final remainder request. Before every render request, call `tape_service`
  with `block_budget == 1024` until `more_work == false`, under a finite guard.
- Every public call returns `TAPE_OK`; every render fills the requested count. Append
  only rendered frames, with no padding, to the candidate PCM. Render performs no
  block I/O; preserve every callback and result in order.
- Concatenate row outputs without gaps. Unmount only after the final hold request.

This call schedule fixes cadence and evidence identity; it does not relax the
normative DRAFT-8 result, interpolation, range, callback or state rules.
