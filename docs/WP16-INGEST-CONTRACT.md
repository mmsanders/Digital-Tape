# WP-16 ingest contract — INGEST-1

**ISSUED by PM, 14 October 2026 PDT, ADR-177.** D3–D5 and WP16 I1–I8 are qualified by the rules below; this document controls where their earlier wording is ambiguous. Basis: [independent preflight #166](https://github.com/mmsanders/Digital-Tape-Verification/blob/c690be9a5f3188333f04ef52a552fcf4c82a0030/findings/P2-R2-WP16-PREFLIGHT-2026-10-14/README.md). Its experiments are planning evidence, not normative waveform goldens or Product acceptance. Changes require PM issuance and paired issue updates. Frozen engine/format bytes remain unchanged.

## 1. Interface and scope

`ingest --out DEST --length SECONDS FOLDER [FOLDER ...]` turns explicitly ordered folders into a new directory containing `audio.wav` and `manifest.json`. SECONDS is a positive integer target label duration; reject overflow. `ingest --version` prints tool version and arithmetic-profile ID without output creation. No device selection/open/write, playback, tag editing or library database. All manifest data stays on the computer. Windows11 x64, current macOS arm64 and Linux x64 are the qualified platforms; record exact builds. One released arithmetic profile must give identical outputs across these platforms; other conforming profiles need distinct IDs, not equality to one another.

Exit 0 only after both files are published; 2 for input/contract refusal; 1 for I/O/tool failure. Stderr names the source/boundary and reason in plain words, including overage. Never silently omit a source or publish a partial result. Help is 0; invalid syntax is 2. No overwrite or automatic erase. Host resources are unrestricted by the engine's embedded RAM budget; a reproducible pinned decoder/resampler/meter stack is Software's choice. No engine/host-port/cadence change is licensed.

## 2. Positive format matrix and source selection (C1/C8)

Inspect actual bytes; suffixes alone cannot admit or refuse otherwise supported content. Supported combinations are:

| Container | Positive codec/profile scope |
|---|---|
| RIFF WAVE | unsigned PCM8, signed PCM16/24/32, IEEE float32/64; extensible equivalents with unambiguous mono/stereo mask |
| AIFF / AIFC | signed PCM8/16/24/32; AIFC NONE or sowt |
| Native FLAC | integer PCM8–32 supported by the published FLAC format |
| MPEG audio | MPEG-1/2/2.5 Layer III, CBR/VBR; not free-format |
| ISO BMFF M4A/MP4 | exactly one unencrypted AAC-LC audio stream, no video/extra audio streams |
| ADTS AAC | AAC-LC |

Exactly one or two channels; mono duplication and stereo channel order are retained. Decoded rates: 7350,8000,11025,12000,16000,22050,24000,32000,44100,48000,64000,88200,96000,176400,192000 Hz where valid for the codec. Refuse zero-frame, changing-rate/channel streams and unsupported rates/profiles. RF64/Wave64, other MPEG layers, Ogg-FLAC, compressed AIFC, ALAC, HE-AAC/HE-AACv2, ADIF/LATM/LOAS and ambiguous channel masks are outside INGEST-1. Refuse them by name, not decoder-dependent opportunistic acceptance.

Folders must exist, be distinct after filesystem identity resolution and contain immediate regular audio files. No recursion or symlink following; refuse symlinks, nested directories, empty folders and unsupported regular files by name. This deliberately requires an audio-only input folder; no implicit hidden/artwork-file skip. A later selection policy is a separate contract amendment. Decode every selected source to completion: reject recognized protected/encrypted entries without acquiring keys, fatal decode/CRC/truncation errors, invalid metadata and nonfinite float samples. Concealed corruption cannot be called success merely because the decoder returns zero. Unknown data is unsupported/corrupt, not a claim of universal DRM detection. Generated protected-header fixtures suffice; no DRM music acquisition.

Sort within each folder as follows: normalize names to NFC; tokenize maximal ASCII digit runs; compare numeric tokens by unbounded integer value and text tokens by Unicode scalar sequence with ASCII A–Z lowercased only. Numeric tokens sort before text tokens. A token-prefix sorts first. Equal primary keys tie by NFC original-case name scalars then original UTF-8 bytes. Thus 1<2<10, 02<2 on a numeric tie, A<a on a case tie; non-ASCII digits are text. Folder order is argument order. Refuse invalid Unicode/unrepresentable names or collisions in normalized logical paths. Manifest paths are `folder_ordinal/NFC_name` with `/`, no absolute roots/drive letters; folder ordinals start at 0. Relocating identical logical inputs changes no output. Case-sensitive source sets unrepresentable on a required OS are refused, not renamed.

## 3. Audio sequence and gain (C2–C5/C11/C12)

Each source is converted alone: reset decoder, trim handling, resampler, meter, gain selection and dither state. Decode/trim → duplicate mono/preserve stereo → isolated floating-point resample to44100 → measure stereo source → one source-wide constant scalar → TPDF/quantize → remeasure final PCM. Mono metering is on duplicated stereo with no extra dual-mono compensation. The mono quantizer below keeps L=R. No compressor/limiter, dynamic loudness processing, fades, crossfades, album gain or neighbour-dependent scalar.

Loudness/true peak follow [ITU-R BS.1770-5](https://www.itu.int/rec/R-REC-BS.1770) and integrated gating in [EBU Tech3341 V4 (2023)](https://tech.ebu.ch/docs/tech/tech3341.pdf). Product target is −16 LUFS, ceiling −1 dBTP. Calibrate loudness meter to ≤0.1 LU error on independent qualification vectors; declare true-peak reconstruction/filter and demonstrate maximum under-read ≤0.1 dB on independent boundary/calibration vectors. Require reported peak+0.1 ≤−1 dBTP. This guard margin does not relax the physical ceiling or assert metering error without validation. Sample-peak alone is insufficient. Incomplete final gating blocks are discarded; do not pad short sources for metering.

For finite input integrated L and true peak P, start gain dB at `min(-16-L, -1-P-0.1)`. Remeasure final quantized source: output loudness must be −16±0.5 LU unless peak limitation prevents it. Reduce the same constant scalar as needed for final peak; recompute deterministic dither from reset state on each attempt. Record target gain, applied gain, measurements and `peak_limited`. An exception must be justified by the peak ceiling or loss of a finite gated result, never by arbitrary under-normalization. Absolute gating can change after gain, so `L+gain` alone is not a final measurement.

All-zero effective source: exact zero output, gain0, measurements null and `digital_silence`. Nonzero source without a finite gated result: no boost; gain `min(0,-1-P-0.1)`, status `unmeasurable`, reason `too_short` or `gated_out`, still enforce peak. If final gain makes gated measurement undefined, record that status rather than invent a finite target. Every source must have a valid peak measurement unless digital silence; otherwise refuse.

Resampler: documented isolated filter, passband error ≤0.1 dB over20Hz…min(18000Hz,0.4×input rate); downsampling alias rejection ≥80 dB relative to steady-state input tones at/above22050Hz and below input Nyquist, excluding explicitly bounded filter transients. Preserve frequency and compensate latency; no intentional time stretch. Acceptance vectors cover transition/end effects separately, with declared support/window and exact output count. Different documented filters may conform; arbitrary one-library waveform hashes are not universal quality oracles. If these bounds prove mutually infeasible on the issued vectors, return the concrete conflict before weakening them.

Concatenate converted source PCM payloads, not WAV headers. No added/dropped/duplicated join frames. Insert exactly88200 stereo all-zero frames between folders, after quantization. Measure final assembled true peak, including every join and gap: if reported peak+0.1 exceeds−1dBTP, refuse naming boundary/source, without gain changes/fades/padding. Gapless means exact presentation-frame concatenation; arbitrary endpoints and independently encoded pieces are not promised click-free or identical to an unencoded source. Matched tone fixtures test known trim/count and bounded fidelity separately.

## 4. Lossy delay/padding and frame counts (C6/C9)

MP3: supported explicit gapless family is Xing/Info with a valid LAME-compatible delay/padding declaration. Validate counts and decoded interval against the actual stream. M4A: support a validated ISO BMFF edit-list presentation interval plus decoder priming/skip data needed to map it to source frames. Only one contiguous presentation interval is admitted. Timescale conversion uses exact rational arithmetic and must yield integer source-frame endpoints; do not invent rounding of fractional trim intervals. Other explicit trim families are unsupported metadata, requiring named refusal when present; legacy iTunSMPB alone is not an admitted interval. If redundant declarations exist, require exact agreement after units/priming conversion; contradiction refuses. Decoder-applied trimming is recorded and applied once, never twice. Reject negative/out-of-range counts, ambiguous endpoints and zero effective frames.

No trim metadata (including ordinary ADTS/legacy MP3): accept the complete decoded sequence untrimmed, status `gapless_unknown`; do not promise original encoder padding removed or scan silence to guess it. Supported validated trim: `gapless_known`, with raw frames/head/tail/effective frames and evidence kind. Unknown/unsupported metadata cannot silently masquerade as known trim. Software declares its pinned decoder's raw/skip semantics and exposes evidence; Verification owns exact encoded-fixture metadata/counts. No decoder-selected semantics can override this interval policy.

For effective decoded length N and rate r, output frames `floor((N*44100 + floor(r/2))/r)` using checked integer arithmetic (nearest/half-up). Filter support may use documented zero extension outside endpoints, but emit exactly this count after latency compensation. Total = sum(source output counts)+88200×(folder_count−1). Capacity=SECONDS×44100. Accept exact fit; one-frame over refuses with exact excess E frames and rounded-up seconds `ceil(E/44100)` displayed mm:ss. All counts include folder gaps. Canonical RIFF size `4*total_frames+36` must fit uint32; refuse overflow before output.

## 5. Exact quantization and reproducibility (C7/C10)

PCM: format1, stereo,44100Hz,16bit signed little-endian, canonical44byte header; byte rate176400, block align4, only fmt/data, no timestamps or extra chunks. Before final quantization reset per-source unsigned32 xorshift state to0x6D2B79F5. Each draw: `s ^= s<<13; s ^= s>>17; s ^= s<<5`, modulo2^32 after each operation, and `u=(s+0.5)/2^32`. Quantize `32768*x+u1-u2` to nearest integer, ties-to-even. Stereo draw order per frame: L(u1,u2),R(u1,u2). Mono: one pair/frame, duplicate quantized sample. No noise shaping or saturation; overflow refuses. Apply TPDF for every floating→16bit output, including gained/resampled16bit sources; only entire digital-silence sources and inserted gaps bypass it. Identical repeated sources reset identically, regardless of path/neighbours/target length.

Tool/arithmetic profile pins decoder/resampler/meter implementations, versions/configuration, scalar rounding and reduction order, PRNG and deterministic gain refinement. Same source bytes/logical names/options/profile must give identical WAV/manifest across qualified OS/architectures. Parallel/FMA/SIMD paths are permitted only after cross-platform equality is established; otherwise use a reproducible scalar path or return a blocker. Profile changes require new ID. Independent conforming alternate-filter positives use distinct profiles, each requiring its own standalone/batch and repeat identity. Libraries pinned alone are not proof of identical floating results.

## 6. Preflight, publication and manifest (C9/C10)

Fully decode/count/validate all sources, ordering, trim, numeric decisions and exact capacity before opening any output or output-staging file. Private in-memory analysis is allowed. Bind source SHA256/file identity across passes; any source mutation refuses, not a mixture of versions. Streaming deterministic re-decode after successful preflight is allowed with validation again. Resource exhaustion exits1 with no published output; no unbounded hidden preflight scratch disk allocation. This literal no-output-before-refusal policy may cost an extra decode pass; a scratch policy change requires issuance.

DEST must not exist. Stage an exclusively created new directory adjacent to DEST containing only audio.wav/manifest.json; close/flush both and publish by a no-replace directory rename or equivalent single-boundary operation on that filesystem. Do not overwrite a concurrently created DEST. Both files appear together; two independent file renames do not satisfy this transaction. Ordinary error removes only the tool's unpublished stage. A killed process may leave an identifiable stage, never a partially published DEST; subsequent runs refuse existing DEST and never automatically delete arbitrary folders. No power-loss durability claim follows merely from rename. Ingest opens no card/block device. Later WP14 loading consumes audio.wav; manifest is never copied to the cartridge.

Manifest schema1: UTF-8 canonical JSON, lexicographically sorted keys, no insignificant spaces, final LF. Numeric counts/options are integers; finite gain/meters are fixed six-decimal strings, half-even and negative-zero normalized; undefined values null with reason. No time, absolute path, random ID, CPU/OS-specific identity or locale text. Require these fields:

| Record | Fields |
|---|---|
| Top level | schema=1,contract=INGEST-1,tool_version,build_profile,libraries (versions/config SHA256),resampler_profile,meter_profile,dither_profile,target_seconds,capacity_frames,total_frames,wav_sha256,folders,sources,gaps |
| Folder | ordinal,source_count; array order is argument order |
| Source | logical_path,source_sha256,container,codec,codec_profile,input_rate,input_channels,raw_frames,trim_head,trim_tail,trim_evidence,effective_frames,output_frames,start_frame,input_lufs,input_dbtp,output_lufs,output_dbtp,target_gain_db,applied_gain_db,peak_limited,loudness_status,loudness_reason,gapless_status |
| Gap | start_frame,frames=88200; ascending source order |

Gain/status observations must agree with actual PCM and interval evidence, not library intent. Exact source bytes and normalized logical paths determine identity. Allowed status/reason values are those named above; normal finite loudness is `measured`/null. Trim evidence is `none`, `xing_lame`, or `bmff_edit`; source names are sanitized only by the issued normalization policy, never dropped. Emit a plain success summary including peak-limited/unmeasurable/gapless-unknown counts so quiet exceptions and unknown trim are visible without on-cartridge metadata.

## 7. Acceptance and dependencies

I1 matrix/strict refusal; I2 resampler/mono/dither/valid WAV; I3 gain-only calibrated final loudness/peak and issued exceptions; I4 isolated exact PCM joins, declared trim, exact zero gaps; I5 exact comparator/folder order; I6 byte-identical same-profile outputs on qualified machines and truthful manifest; I7 exact gap-inclusive frame capacity and pair transaction; I8 generated-tone/CC0/public-domain licence census. Independent tests require causal controls and alternate conforming-path positives. Preflight evidence is not a landed acceptance oracle. Use the proposed six-row/34-case census as a minimum coherent boundary, expanding only where required for this contract.

Host authoring and implementation may overlap after issuance under the host-tool independence rule. Verification does not inspect implementation before its oracles. Exact-head independent disposition, imported published identities, required CI and Software-owned integration remain separate. No ingest implementation is assigned by this document itself. No real-card WP16 integration/full-package or WP15 acceptance before WP14 physical A6 closure. Windows success/timing/README are already independently accepted; no repeats. Hardware/media/atomicity/<30s/write/batching/async/recording/format-freeze holds survive.
