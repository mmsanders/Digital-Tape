## Interface

One window, one job: **drop music in, get a cartridge out.**

1. Drop one or more folders; individual files or mixed file/folder drops are refused. The window shows the total length against the cartridge
   length as a single bar, not a list.
2. Type a label (stored in the superblock `label`, 32 bytes UTF-8).
3. Insert a card. Only cards that pass WP-14's safety rules can be chosen.
4. Press one button. A progress bar runs; when it finishes, the window says the card is safe to remove.

The app runs WP-16's ingest tool and then `tapectl` (plan §3). It never opens a block device for
writing itself. PM issues the exact contract (screens, wording, refusal messages) in P2-R3.

**Guardrail 03 applies to the app.** If a proposed feature would show the user a list of anything,
such as tracks, files or cartridges, it is the wrong feature. The app is not a player, library, tag
editor or music manager.
