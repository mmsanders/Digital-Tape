## Interface

A command-line tool turns ordered sources into one canonical WAV that `tapectl load` accepts:
44.1 kHz, 16-bit, stereo, canonical 44-byte header. It also writes a manifest beside the WAV:
the sources in order, each one's decoded length and applied gain, and the tool and library versions.
The manifest stays on the computer. **Nothing from it is stored on the cartridge** (guardrail 03).
The exact [INGEST-1 contract](../WP16-INGEST-CONTRACT.md) is issued in P2-R2.

Ingest converts input formats. It never stores compressed audio (guardrail 01), and it is not format
logic, so it may be written in any language (plan §3).

## Acceptance criteria

| # | Criterion |
|---|---|
| I1 Formats | Every D3 format is accepted. Exact positive combinations are INGEST-1 §2 (ADR-180: AIFC `sowt` is 16-bit only; ADTS is one raw data block per frame). Anything else is refused by name. DRM-protected files are refused with a plain message, never silently skipped |
| I2 Conversion | Mono is duplicated to both channels. Other rates are resampled to 44.1 kHz with a documented filter. Reduction to 16 bits uses TPDF dither. The output is accepted by `tapectl load` |
| I3 Loudness | Gain only; no compression or limiting (D4). After gain, finite measurable sources reach ±0.5 LU of the D4 target where feasible under the peak ceiling; INGEST-1 defines peak-limited, digital-silence and unmeasurable exceptions, calibrated final metering and joined-output refusal. No output sample exceeds the D4 true-peak ceiling. A source that would exceed it gets less gain, and the manifest records that |
| I4 Gapless | Inside one folder, the output is exactly the concatenation of each source converted alone. No samples are added, dropped or duplicated at a join. Supported validated MP3/AAC gapless metadata defines exact presentation trimming; absent metadata is admitted untrimmed with gapless_unknown. INGEST-1 forbids guessed/double trimming. Encoded-piece fixtures test exact frame/count semantics and bounded fidelity, not lossless recovery or arbitrary endpoint continuity. Between folders, the D5 gap is exact digital silence of the stated length |
| I5 Order | D5 order (natural filename order within a folder; folders in the order dropped). The same input always gives the same order |
| I6 Determinism | Same inputs and same tool version give a byte-identical WAV and manifest. Library versions are pinned and recorded |
| I7 Length | Any source whose exact resampled count is zero refuses by name/exit2 before output (ADR-178), including silence; positive short sources remain admitted. If the total exceeds the target cartridge's label length, ingest refuses before writing output and states the overage in minutes and seconds |
| I8 Fixtures | Test material is generated tones or public-domain/CC0 recordings only, as with the WP-11 goldens |
