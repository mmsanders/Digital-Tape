# WP-16 — Ingest: gapless join, loudness normalisation

**Stream:** 3 host tooling · **Owner:** Software builds; Verification accepts
**Status:** not started. Proposed criteria, issued with [the Phase 2 plan](../PHASE2-PLAN.md) (ADR-161)
**Depends on:** kickoff decisions D3 (formats), D4 (loudness), D5 (order and gaps); WP-14 for the real-card half · **Blocks:** WP-15

## Interface

A command-line tool turns ordered sources into one canonical WAV that `tapectl load` accepts:
44.1 kHz, 16-bit, stereo, canonical 44-byte header. It also writes a manifest beside the WAV:
the sources in order, each one's decoded length and applied gain, and the tool and library versions.
The manifest stays on the computer. **Nothing from it is stored on the cartridge** (guardrail 03).
PM issues the exact contract in P2-R2.

Ingest converts input formats. It never stores compressed audio (guardrail 01), and it is not format
logic, so it may be written in any language (plan §3).

## Acceptance criteria

| # | Criterion |
|---|---|
| I1 Formats | Every D3 format is accepted. Anything else is refused by name. DRM-protected files are refused with a plain message, never silently skipped |
| I2 Conversion | Mono is duplicated to both channels. Other rates are resampled to 44.1 kHz with a documented filter. Reduction to 16 bits uses TPDF dither. The output is accepted by `tapectl load` |
| I3 Loudness | Gain only; no compression or limiting (D4). After gain, each source measures within ±0.5 LU of the D4 target, by EBU R128 integrated loudness. No output sample exceeds the D4 true-peak ceiling. A source that would exceed it gets less gain, and the manifest records that |
| I4 Gapless | Inside one folder, the output is exactly the concatenation of each source converted alone. No samples are added, dropped or duplicated at a join. MP3/AAC encoder delay and padding are removed using the file's gapless metadata. Fixture: one continuous tone split into encoded pieces must decode and join to an unbroken tone. Between folders, the D5 gap is exact digital silence of the stated length |
| I5 Order | D5 order (natural filename order within a folder; folders in the order dropped). The same input always gives the same order |
| I6 Determinism | Same inputs and same tool version give a byte-identical WAV and manifest. Library versions are pinned and recorded |
| I7 Length | If the total exceeds the target cartridge's label length, ingest refuses before writing output and states the overage in minutes and seconds |
| I8 Fixtures | Test material is generated tones or public-domain/CC0 recordings only, as with the WP-11 goldens |

## Independent sign-off

Verification Lead only. Disposition of an exact head against the WP-16 contract and these criteria.
